# 8.5 分目标：本轮改进与验收

本轮以减少录入负担、清晰区分事实与推断、改善记忆查阅和可靠返回为重点。8.5 是产品目标，不是自动测试得出的评分。

## 改动

| 范围 | 改动 | 用户价值 |
| --- | --- | --- |
| 现在 | 标签可不填；保存入口明确；链接支持裸域名；拒绝无效链接和错误媒体类型；读取失败提示重试 | 降低记录门槛，减少无效材料 |
| 草稿 | 未保存内容刷新或关闭时触发浏览器离开提醒 | 减少误刷新丢失；不等于自动恢复 |
| 过去 | 回归验证逐条勾选、键盘切换、取消和删除范围；修正过期测试入口 | 确保删除操作可见、可选、范围明确 |
| 模式 | 去重来源 ID，过滤部分引用、他人描述及计划性文字；“延后行动”不再直接推断心理压力 | 减少无依据的个人标签 |
| 未来 | 行动完成使用“行动已完成”；非完成状态不误导跳往过去；移除直接查看变化的误导入口 | 区分完成一次行动与形成长期成长 |
| 分身 | 当前主题跨维度搜索、抽屉显示已确认记忆摘要；返回和切换主题清理查询；候选记忆不作为已确认内容展示 | 减少查找层级与认知混淆 |
| 手机界面 | 修复输入区域旧深色样式覆盖导致的颜色问题；摘要换行与截断 | 保证可读性与窄屏稳定 |
| 告知 | 隐私文案说明相关内容可能发送给所选 AI 服务商 | 与实际处理方式一致 |

## 验证方式

- 使用隔离的浏览器上下文和模拟数据，未删除用户真实记录。
- Chromium 测试包含 1440、390 及部分 320 像素视口；这不等同于真机验证。
- 浏览器回归已验证：取消记忆提炼、相似愿景确认、320px 长规划保存及返回、现在无标签保存、素材添加移除、过去逐条勾选及保留未选记录，共 7 项通过。
- 构建和 TypeScript 检查通过；最终补充检查结果见下文。
- 全量单元测试：159 个文件通过，1102 项通过，1 项预期失败（未保存输入强制关闭恢复），总计 1103 项。
- ESLint：修复两处 error（未使用导入及不合适的导航角色）；涉及文件复检无 error，但仍有大文件和外观设置标签告警。项目采用零 warning 门槛，因此不能宣称全仓 lint 已通过。
- 补测：现在录入桌面版单独重跑通过；过去原则完整操作在独立构建预览环境下，1440 / 390 两个视口均通过（新增、修改、取消修改、删除、返回、搜索、无横向溢出及页面自动无障碍检查）。
- 开发预览上的补测曾被页面重载至解锁页中断；相同操作在独立构建预览中未复现，原因尚未确认，不能将其解释为已经修复。

## 仍有明确限制

1. 未保存输入在强制关闭或组件卸载后的恢复尚未实现，测试保留一项预期失败明确记录此缺陷。浏览器离开提醒不是持久化保障。
2. 模式过滤属于启发式规则，不能代替真实模型提炼准确率评测或用户确认。
3. 本轮未证明真实 API 额度、网络环境、真实手机 Safari、跨设备数据恢复与长期使用质量。
4. 工程中仍有大文件告警；不通过关闭规则来伪造检查通过。
5. 本地链接只供当前电脑查看，没有据此宣称对外部署完成。

## 对 8.5 分的判断

本轮已修复多项明确摩擦点，但不能凭代码改动数或测试数换算产品分数。达到稳定的 8.5 分还需要真实用户完成记录、行动规划、践行记录、形成可确认理解的连续使用验证，并量化失败率、重复录入和误判情况。
