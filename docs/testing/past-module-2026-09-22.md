# 过去模块测试与修复（2026-09-22）

## 范围与隔离

测试“回看 / 沉淀”，使用独立浏览器数据和 3120 测试服务；未使用或删除用户资料。3010 服务工作目录为当前项目。

## 修复

- 以明确的删除对话框替换连续原生确认，避免第二次取消被理解为级联删除。
- 删除弹窗默认保留相关知识，取消按钮初始聚焦，Escape 取消。
- 搜索变化清除选择，避免误删搜索后不可见的条目。
- 新增、更新、删除等待保存完成；失败保留内容并提示重试。
- 原则编辑提供保存与取消，未保存内容离开前确认；刷新使用浏览器离开提示。
- 添加年份范围校验与重复提交保护。
- 统一编辑区深色配色、提示文字对比度和移动输入字号，扩大主要操作点击区域。

## 用户指出选框缺失后的补测

此前测试只验证了选择控件存在，没有验证未选中时的可见边框，漏掉了桌面样式缺失，原报告不能代表全部交互细节已经通过。

- 原因：共用记录组件的选择样式仅覆盖移动容器，桌面空选框没有可见边框。
- 修复：桌面和手机共用显式选框、选中态、键盘焦点、选择工具栏和删除按钮样式；删除栏不再覆盖最后一条记录。
- 新增两个真实浏览器用例（1440 / 390）：模拟新增两条记录，检查选框伪元素边框和尺寸、单选、Space 切换、全选、取消全选、退出选择重置、Escape 取消删除及重新确认，只删除所选记录并保留另一条；检查横向溢出和删除栏不遮挡记录。
- 相关组件单元测试 24/24 通过。模拟数据使用独立浏览器存储，未操作用户的真实记录。
- 首次桌面补测遇到开发服务页面重载；后续桌面和手机完整流程均通过，未复现 Escape 导致锁定，未因此改动键盘处理逻辑。

最终布局复测：390 手机用例通过；1440 桌面单独重跑通过（40.1 秒），两端均验证删除栏位于最后一条记录下方，并人工检查选中态截图。当前 3010 服务返回了本次更新的 CSS。
