# 资料库检索性能基线（2026-10-09）

「过去」只保留关键词检索与标签筛选。日期、关联筛选、关系索引和事实回顾已删除，旧基准不再作为当前验收依据。

## 范围与预算

- 合成数据规模：1,000 / 10,000 条记录。
- 标签筛选：10,000 条记录的纯计算中位数预算为 100 ms。
- 空筛选：保留全部关键词命中结果。
- 初次呈现最多 100 个记录卡，按批加载；全选删除仍基于完整结果集。

运行 `npm run bench:past-search`，每个场景预热 3 次、测量 15 次并报告中位数。脚本只测标签与空筛选；关键词检索由组件测试覆盖。

性能预算不作为跨机器 CI 的硬失败条件。筛选语义由 `features/mobile/pastSearch.test.ts` 验证，批量呈现由 `PastRepository.test.tsx` 验证。

本基线不测媒体解码、备份、数据库读取、浏览器冷启动或网络，也不代表低端设备的实际体验。
