# 分身对话接入与验收

2026-09-16：通用陪聊已从关键词回复切换为 `/api/v1/avatar/chat` 模型调用。

## 已接通

- 输入 → 最近 40 条对话 → 相关记忆及称呼 → 六层规则 → 模型回复。
- 记录整理、工具模式保持原有独立流程；模型回复本身不写入正式记忆。
- 等待状态、防重复提交、卸载取消、错误提示、保留消息并重试。
- 后端输入校验、来源鉴权、限流、45 秒超时、上游错误隔离。
- 当前记忆检索沿用本地相关性规则，尚不是语义向量检索。

## 用户自行接入与选择模型

在分身陪聊顶部打开「模型接入」，选择服务商或填写兼容 OpenAI Chat Completions 的公网 HTTPS 地址和 API Key。点击「获取模型列表」后选择模型，也可手动填写模型 ID。模型列表可能含非聊天模型，应测试后使用。

「测试连接」只发送测试消息；「保存并使用」后，下一次聊天和失败重试使用该配置。清除个人配置后恢复服务端默认连接。个人配置优先于环境变量。

配置存放在当前标签页的 sessionStorage，刷新保留，正常结束标签页会话后失效（浏览器恢复会话可能保留）。不写入 localStorage、正式记忆或服务器配置文件。密钥随请求到本应用服务器，再转发至所填服务商；当前不是加密持久化密钥库。请仅在可信设备使用。

新增接口：POST `/api/v1/avatar/model/list`、POST `/api/v1/avatar/model/test`；聊天支持 `modelConfig`。自定义接口限制公网 HTTPS，DNS 解析结果校验并固定实际连接地址，不跟随重定向。

## 管理员默认连接

在项目根目录 `.env.local` 配置现有支持的供应商之一：

```dotenv
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=你的密钥
OPENROUTER_MODEL=你账号可用的模型ID
```

或者：

```dotenv
AI_PROVIDER=gemini
GEMINI_API_KEY=你的密钥
GEMINI_MODEL=gemini-2.5-flash
```

重启 `npm run dev`，访问 `/api/health` 查看 provider/model 是否非空。密钥只在服务端使用，不放进前端配置或聊天消息。

## 验收要求

1. 输入从未预设的问题，例如“叶子为什么是绿色”，随后追问“用小学生能懂的方式解释”，应保留上下文。
2. 输入“你好”“今天有点烦”“你理解错了”，回复长度、语气应随语境变化。
3. 询问没有记录过的个人经历，应明确未知，同时仍能回答通用知识问题。
4. 对话完成后，未经用户确认，正式记忆数量不得增加。
5. 禁用模型配置后，应显示连接错误和重试入口，不应生成冒充模型的预设回复。

接口与组件测试使用模拟模型验证调用路径，不能证明真实供应商质量。当前本机供应商未配置，真实模型多轮对话效果仍待接通后验收；不能宣称已达到参考视频的相同效果。
