# 后续实证验证协议

版本：p0-p2-20261123。本文是可执行计划，**不是已完成的模型实验、真人研究或设备测量结果**。

## 中英文模型对照

当前 englishHoldout 含 6 个英文、6 个混合案例，验证确定性意图/回答协议；它未调用真实 embedding 或远程模型，不能证明英文检索质量。

准备中文、英文、中英混合各 50 个独立任务，覆盖近义检索、日期约束、否定、反例、无证据拒答、事实更新、歧义与跨条目引用。全部使用授权的合成或匿名数据，禁止从真实私密日记直接复制。开发集与 holdout 按人物和事件隔离，冻结 JSON、标注与 SHA256，调参后不得重复使用 holdout 当训练集。

在同一任务、切块规则、top-k、硬件和冷/热缓存条件下对比现有中文模型、候选多语言模型及可选语言路由。固定模型 ID/revision、量化、运行库、随机种子与提示词。分别报告三组 Recall@5、MRR、引用来源准确率、正确拒答率、无依据结论率、p50/p95 延迟、峰值内存、模型及运行时字节。人工双人盲评冲突由第三人裁定，给出样本量及置信区间；不可只报总体均值掩盖英文退化。

决策门槛预先确定：隐私过滤零已知失效；引用与无依据结论不得退化；英文 Recall@5 绝对提升至少 5 个百分点且中文降低不超过 2 点，才考虑迁移；同时符合目标设备资源预算。小样本区间重叠时扩大样本，不能仅凭单次差值换模型。

## 10–15 人、7 日试用

招募假设：有真实复盘习惯的中文和英文使用者，兼顾手机/桌面、轻量记录/深度复盘。先明确知情同意、退出方式、观察范围和数据删除期限。此版本不增加遥测，不自动邀请或收集原文；由参与者自愿提供匿名任务结果。招募与实际观察尚未开展。

首日任务：从空白安装直接记录 → 选择仅自己可见 → 在 Past 回看 → 刷新确认 → 理解授权含义 → 可选授权一条非敏感记录并查看 AI 证据。观察权限弹窗是否被误认为新手引导；记录完成时长、卡点、误操作与解释是否需要帮助。

| 指标          | 定义与采集                                                         |
| ------------- | ------------------------------------------------------------------ |
| 首条完成      | 无协助完成保存、回看、刷新恢复的人数 / 尝试人数；同时报绝对人数    |
| 权限理解      | 能解释私有、允许和撤权不能收回已发内容的人数；用复述而非满意度代替 |
| 有效回看      | 自述回看帮助理解具体事件，并能定位原文；不收集该原文               |
| 重复使用      | D1–D7 至少两个不同日期真实主动记录；D7 活跃另报                    |
| AI 价值与纠错 | 有依据回答、无依据回答、错误记忆及人工修改/拒绝的次数              |
| 付费意向      | 访谈愿为哪项价值付费、可接受区间与理由；意向不当实际转化           |

第 2/4/7 天自愿简短回访。按 10–15 人的小样本逐案总结，不外推市场留存。任何数据丢失、私有内容发送或错误授权立即停止该场景；先修阻断。首轮目标是找出至少前三个可重复问题，再决定是否改权限交互或增加引导；不得默认恢复强制启动引导和样例记录。

## 真实设备与离线基线

Lighthouse 的移动模拟不能替代实机。至少选一台 4 GB Android 中端机、一台 iPhone 与普通笔记本；记录设备/OS/浏览器/版本、供电、温度、网络 RTT/带宽/丢包、测试日期。每组合冷/热启动各 5 次，先静置再测试，不与构建/其他基准并行。

分别测首页可输入、首次记录保存、Past 回看、首次语义初始化及后续检索 p50/p95，记录 CPU、峰值内存和请求字节。独立区分首屏 JS/CSS、PWA 安装预缓存、按需 ONNX 和运行时 wasm；运行时多种分发文件总量不是单个用户必然下载量。

离线场景：首次无网络、已缓存离线写入/刷新、语义模型未缓存、模型已缓存、断网中途、旧 SW 升级。私有/API 响应不得进入 SW 缓存；模型失败应可恢复，不能阻断普通记录。实机数据未达标时针对热点 profiling，不凭文件大小重写整个架构。
