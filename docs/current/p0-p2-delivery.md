## 验证结果

- Vitest：188/188 文件通过，1,357/1,357 测试通过。
- Playwright：36 项中 35 项通过。唯一失败为 1440px 的“未来草稿刷新恢复并在保存后清理”场景；失败定位在重载后寻找“未来”导航按钮超时，390px 对应场景通过。单项复测受当前执行环境的本地监听权限限制，未能启动，不能记为通过。
- ESLint：通过，零 warning。
- Prettier：通过。
- TypeScript：`npm run typecheck` 通过。
- 构建：`npm run build` 通过。Vite 提示 `vaultTransaction.ts` 与 `MobileShell.tsx` 同时被静态和动态导入，因此相关代码不会因该动态导入单独拆分成 chunk；未影响构建通过。
- Lighthouse：桌面性能 100、无障碍 100、最佳实践 100、SEO 91；移动性能 88（低于 90 门槛）、无障碍 100、最佳实践 100、SEO 91。移动性能门禁未通过，移动性能门槛（90）未通过。原始审计报告留在开发工作区的 `lighthouse-reports/`，不包含在本交付 ZIP 中。Stripe 沙箱、实体设备/弱网、真实模型质量对比、用户研究：尚未完成。

## 复现命令

在 Node.js 与 npm 环境安装依赖后，可运行 `npm run typecheck`、`npm run lint`、`npm run format:check`、`npm run test`、`npm run build` 和 `npm run audit:resources`。Playwright 全量结果为 35/36；已知桌面 1440px 用例失败，受当前环境本地监听权限限制未能单项重跑。

## 对外使用边界

可以将本包用于源代码评测、复现单元测试与审阅 P0–P2 工程改动。不能据此宣称整库加密、商业付费就绪、英文模型效果已证实、无幻觉或已完成真实用户验证。付费上线的首要阻断项是持久化授权状态与退款/重复 webhook 生命周期；性能判断应等待指定设备的实测。
