# 可选整库加密：设计与验收约束

版本：p0-p2-20261123。状态：**设计完成；整库迁移未实现、未验收**。当前实现以 PRIVACY.md 为准。

## 产品边界

首次使用直接 NOW；不添加启动引导、强制密码或示例数据。整库保护只能由用户在设置中主动开启。主锁、指定数据加密、备份加密继续分别描述。加密不解决已解锁设备、恶意扩展、XSS、截图、系统备份或已发送 AI 内容泄露。

## 覆盖范围与密钥

在 PRIVACY.md 的存储矩阵上逐项登记记录正文/标题/标签/补充、素材及内嵌二进制、原则、记忆、对话、未来、行动、草稿、恢复日志、镜像和向量缓存。普通 UI 偏好可明文；敏感索引不能以便于搜索为由默认明文。向量缓存清除后重建，不迁移旧明文。

每账号使用独立随机数据密钥 DEK，AES-GCM 加密各对象，独立随机 nonce；AAD 绑定账号、对象 ID、数据类型及 schema 版本。密码派生 KEK 仅用于封装 DEK，保存算法版本、盐及参数。KDF 必须在目标设备实测后确定；现有密码验证 Argon2 与现有加密 PBKDF2 不可混称。明文密码、DEK 不写 localStorage、日志或同步配置；锁定/切账号销毁内存引用并停止 worker。JS GC 无法保证物理内存即时擦除，应诚实说明。

改密码重新封装 DEK，数据密钥轮换另行迁移。恢复方式需明确选择独立恢复密钥或不可恢复模式；不得声称服务器能恢复未知密码。不创建隐藏托管密钥。

## 两阶段迁移与回滚

1. 导出并校验可恢复备份；确认可用磁盘空间足以同时保存原库与新库。暂停写入、同步和语义 worker，使用账号级独占迁移锁与所有标签页通知。
2. 保存版本化迁移日志：账号、源 revision、对象数、每批状态和校验值。写入独立目标命名空间，保持原库完整；迁移日志本身不含正文或未封装密钥。
3. 分批加密后逐项解密比对 canonical 数据校验和及数量，并校验附件、跨记录来源引用、草稿与账户归属。检测源 revision 变化时中止，不覆盖并发写入。
4. 只有全部验证成功才以单一事务提交 active-generation 指针。重启仅读取已提交 generation；未提交目标可续传或丢弃。跨 localStorage/IDB 无原子事务，必须通过 generation 协议管理，禁止先删源库再复制。
5. 切换成功并再次启动验证后清理旧明文、localStorage 镜像、向量缓存和相关 Cache Storage。浏览器删除不保证磁盘安全擦除。原始备份由用户自行管理。
6. 提交前失败直接恢复源库；提交后回滚必须验证备份和新写入，禁止自动回旧库丢掉新增内容。关闭保护须重新验证密码、显式告知明文边界并走同等迁移流程。

## 发布验收矩阵（全部待执行）

| 场景                             | 必须满足                                                   |
| -------------------------------- | ---------------------------------------------------------- |
| 错误密码、错误恢复密钥           | 不读取正文、不修改源库；错误不泄露密钥状态                 |
| nonce/ciphertext/AAD 篡改        | 验证失败即停止，不导入部分损坏数据                         |
| 逐批中断、标签页崩溃、空间耗尽   | 源库可恢复；重复续传无重复对象、无丢失                     |
| 账号切换、多标签并发、同步同时写 | 隔离账号，拒绝旧会话写入，校验 revision                    |
| schema 升级、旧备份恢复          | 旧格式先严格验证，再转换；对象与关联逐项一致               |
| 新旧密码、轮换、关闭保护         | 旧凭据失效边界明确；恢复后无静默丢失                       |
| 本地专用标记扫描                 | 所有敏感存储位置及缓存不残留新明文；扫描含标题、标签与附件 |
| 大库与低端手机                   | 峰值内存、耗时、空间、可取消和恢复能力符合实测预算         |

上线前需要独立安全评审与设备故障演练。当前 storageBoundary.test.ts 验证的是**现有局部保护和备份边界**，不能算作本方案迁移测试。
